# Set up a new laptop

### 1. Sign in
Who: New starter
Sign in with the email and the one-time password from your welcome email.

### 2. Set your password
Who: New starter
At least 14 characters. You'll be asked to set up the authenticator app.

### 3. Install updates
Who: New starter
Let the updates finish before anything else; it can take 20 minutes.

### 4. Open the shared drive
Who: New starter
It appears in the sidebar once updates finish.

### 5. Add the printer
Who: New starter
Settings, Printers, Add: choose Fernlow-Office.

### 6. Tell Dev
Who: New starter
Message Dev Chauhan that you're set up, so your old temporary account is closed.
